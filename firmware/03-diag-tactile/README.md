# Diagnostic du tactile

Programme autonome, sans l'interface. Tout s'affiche sur l'écran de la carte.

1. **Pression (15 s)** : appuie doucement puis fort à plusieurs endroits. La barre devient verte au-delà du seuil.
2. **9 cibles** : touche le centre de chaque cible, lève le doigt entre chaque.
3. **Résultat (8 s)** : chaque cible affiche son écart en pixels (vert < 8, jaune < 15, rouge au-delà).
   **Prends une photo de cet écran.**
4. **Dessin libre** : le point vert doit suivre ton doigt.

Le moniteur série (115200) affiche les mesures : lignes PRESSION, CIBLE, ECART et COEF.
